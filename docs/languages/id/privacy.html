Buku harian Anda tetap ada di perangkat Anda

Anda memilih apa yang akan dicatat: makanan dan minuman, bahan-bahan, gejala dan perasaan positif, tanggal, tingkat keparahan gejala, stres, tidur, catatan, dan ulasan harian. Bellywise menyimpan buku harian Anda di iPhone atau iPad dan menghitung pola eksplorasinya di sana. Anda tidak memerlukan akun. Bellywise tidak mengunggah buku harian Anda ke server yang dioperasikan pengembang dan tidak menyertakan SDK periklanan atau analitik.

Aplikasi asli menggunakan database terenkripsi SQLCipher. Kunci enkripsi acak disimpan di penyimpanan kunci aman perangkat dan hanya tersedia saat perangkat tidak terkunci. Ini dikonfigurasi untuk tetap berada di perangkat itu. Enkripsi bergantung pada keamanan perangkat Anda, kode sandi, dan perlindungan sistem operasi; ini bukan jaminan terhadap akses ke perangkat yang tidak terkunci atau disusupi.

Bellywise tidak menyediakan sinkronisasi cloud atau salinan server buku harian Anda. Sistem operasi Anda mungkin menyertakan file aplikasi dalam cadangannya sendiri. Kunci enkripsi yang terikat perangkat mungkin tidak ditransfer bersama file tersebut. Sebelum mengganti atau mengatur ulang perangkat, simpan cadangan Bellywise dari Ruang saya dan simpan secara pribadi.

Kamera, foto, dan pengenalan bahan

Akses kamera bersifat opsional. Anda dapat memindai kode batang produk atau memotret daftar bahan. Pengenalan teks bahan menggunakan Apple Vision di perangkat. Bellywise tidak mengunggah foto label atau video kamera. Anda juga bisa memilih foto yang sudah ada atau memasukkan bahan secara manual.

Foto label disimpan sementara di cache aplikasi saat Anda memilih area bahan. Bellywise mencoba menghapus salinan sementara tersebut ketika pemrosesan selesai, Anda mengabaikan formulir, atau pengenalan gagal. Ini tidak menghapus gambar asli dari perpustakaan foto Anda. Teks bahan yang Anda simpan menjadi bagian dari buku harian lokal Anda.

Informasi produk online opsional

Memindai kode batang meminta catatan produknya dari Open Food Facts. Memilih pencarian produk online mengirimkan istilah pencarian, merek atau kode batang dan pasar yang dipilih ke Open Food Facts. Permintaan ini mencakup informasi koneksi internet biasa, seperti alamat IP Anda, waktu permintaan, dan agen pengguna aplikasi. Itu tidak menyertakan buku harian, gejala, catatan, atau foto label Anda. Jangan sertakan detail pribadi atau medis di bidang pencarian produk.

Open Food Facts mengoperasikan layanannya sendiri dan dapat menyimpan koneksi dan meminta log berdasarkan kebijakannya sendiri. Kebijakan Open Food Facts yang dipublikasikan mencantumkan retensi alamat IP pengunjung dan log selama tiga tahun untuk keamanan, analisis teknis, dan pengukuran popularitas. Bellywise tidak dapat menghapus catatan penyedia. Anda dapat menggunakan entri makanan manual dan pengenalan bahan lokal tanpa pencarian produk online.

Notifikasi dan widget Layar Beranda

Jika Anda mengaktifkan pengingat, Bellywise menjadwalkannya secara lokal di perangkat Anda pada waktu yang Anda pilih. Notifikasi pola baru juga dihasilkan secara lokal saat aplikasi memeriksa buku harian Anda. Bellywise tidak mendapatkan token push jarak jauh atau mendaftarkan buku harian Anda dengan server notifikasi Expo. Teks notifikasi dapat menyebutkan suatu bahan dan perasaan, sehingga dapat mengungkapkan informasi pribadi di layar kunci Anda tergantung pada pengaturan iOS Anda. Anda dapat menonaktifkan peringatan di Bellywise atau Pengaturan iOS.

Widget Layar Beranda menyediakan pintasan ke dalam aplikasi. Itu tidak menampilkan buku harian Anda atau mengirimkan isinya ke server.

Ekspor, pencadangan, dan situs web lainnya

Anda mengontrol apakah akan mengekspor laporan atau cadangan, dan di mana menyimpan atau membagikannya. Laporan yang diekspor dan cadangan JSON berisi data buku harian yang dapat dibaca dan tidak memiliki enkripsi database aplikasi. Tujuan yang Anda pilih, seperti File, layanan email, atau penyimpanan cloud, mengontrol penyalinan tersebut. Bellywise mencoba menghapus file cache ekspor atau impor sementara setelah operasi berakhir.

Saat Anda membuka sumber pendidikan atau halaman produk, browser Anda dan situs web tersebut menerima informasi koneksi biasa dan menerapkan praktik privasinya sendiri. Mengunjungi halaman dukungan atau privasi Bellywise juga melibatkan pencatatan koneksi normal host situs web.

Halaman dukungan dan privasi Bellywise dihosting oleh Halaman GitHub. Halaman ini tidak menyertakan iklan, skrip analitik, atau formulir kontak. GitHub memproses informasi koneksi normal saat Anda berkunjung, di bawahnya pernyataan privasi.

Mendukung korespondensi

Jika Anda mengirim email ke dukungan, penyedia menerima alamat, pesan, dan lampiran yang Anda pilih untuk dikirim. Informasi ini digunakan untuk menjawab permintaan Anda dan menyelidiki masalah, dan ditangani melalui layanan email penyedia. Bagikan hanya yang diperlukan saja. Gunakan entri buku harian fiksi atau hapus detail sensitif dari tangkapan layar jika memungkinkan. Anda dapat menghubungi alamat privasi di atas tentang akses, koreksi, penghapusan dan penyimpanan informasi yang telah Anda kirimkan ke dukungan.

Retensi, penghapusan, dan pilihan Anda

Entri buku harian tetap ada secara lokal hingga Anda mengedit atau menghapusnya, mengatur ulang buku harian, atau menghapus file aplikasi yang disimpan. Ruang saya menyediakan kontrol ekspor, pencadangan, dan penghapusan buku harian. Memulai buku harian baru setelah kesalahan penyimpanan akan mempertahankan database lama yang tidak dapat dibaca sehingga tidak ditimpa. Menghapus buku harian aktif tidak menghapus file yang disimpan secara terpisah, cadangan sistem operasi, ekspor atau salinan yang telah Anda bagikan. Bellywise tidak dapat memulihkan catatan dari server pengembang karena tidak ada server buku harian.

Anda dapat menolak akses kamera dan notifikasi dan terus menggunakan entri manual. Anda dapat menghindari pencarian online. Untuk permintaan mengenai log layanan pihak ketiga, hubungi layanan tersebut menggunakan kebijakannya di atas. Tergantung di mana Anda tinggal, Anda mungkin memiliki hak untuk mengakses, memperbaiki, menghapus atau membatasi informasi pribadi, menolak pemrosesan tertentu, atau mengajukan keluhan kepada otoritas perlindungan data setempat. Hubungi alamat privasi di atas untuk informasi yang disimpan oleh penyedia Bellywise; penyedia tidak dapat mengakses buku harian perangkat Anda kecuali Anda memilih untuk mengirimkannya.

Audiens dan perubahan

Bellywise dimaksudkan sebagai buku harian orang dewasa dan alat pendidikan. Ini tidak mendiagnosis intoleransi, alergi atau kondisi medis lainnya dan tidak dimaksudkan untuk mengatur pola makan anak-anak. Jika praktik data ini berubah, kebijakan ini akan diperbarui dengan tanggal baru.
