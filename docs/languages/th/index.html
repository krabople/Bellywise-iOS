bellywise
การสนับสนุนความเป็นส่วนตัว

ไดอารี่อาหารและอาการ

เข้าใจอาหารและความรู้สึกของคุณ

Bellywise ช่วยให้คุณจดบันทึกอาหารและอาการ และสำรวจรูปแบบที่ควรปรึกษากับผู้เชี่ยวชาญด้านสุขภาพ

เราพร้อมให้ความช่วยเหลือ

พบคำตอบเชิงปฏิบัติได้ใน การสนับสนุน · Bellywiseหรืออ่านวิธีจัดการข้อมูลของคุณใน นโยบายความเป็นส่วนตัว.

บันทึกอาหารและเครื่องดื่ม บันทึกความรู้สึก ทบทวนวันของคุณ และดูหลักฐานเบื้องหลังส่วนผสมและอาการที่เป็นไปได้ ผลลัพธ์ของรูปแบบเป็นความสัมพันธ์เชิงสำรวจ ไม่ใช่ข้อพิสูจน์ถึงการแพ้อาหารหรือการแพ้

Bellywise is provided by Benjamin David Berger.
