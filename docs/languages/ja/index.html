食事と症状の日記

食べ物と感情を理解しましょう。

Bellywise は、食事と症状の日記を付け、医療専門家と話し合う価値のあるパターンを探るのに役立ちます。

ここでお手伝いします

実践的な答えは次のとおりです。 お腹周りのサポート、または、あなたの情報がどのように扱われるかを読んでください。 プライバシー ポリシー.

食べ物や飲み物を記録し、気分を記録し、一日を振り返り、考えられる成分と症状の関連性の背後にある証拠を調べます。パターンの結果は探索的な関連性であり、食物不耐症やアレルギーの証拠ではありません。

Bellywise は Benjamin David Berger によって提供されています。

サポートプライバシーポリシーデータソースとライセンス

食事と症状のパターンは調査の手がかりであり、医学的診断ではありません。
