Mat- og symptomdagbok

Forstå maten og følelsene dine.

Bellywise hjelper deg med å føre en mat- og symptomdagbok og utforske mønstre som er verdt å diskutere med en helsepersonell.

Her for å hjelpe

Finn praktiske svar i Støtte · Bellywise, eller les hvordan informasjonen din håndteres i personvernerklæring.

Registrer mat og drikke, logg hvordan du føler deg, se gjennom dagen din og se på bevisene bak mulige ingrediens- og symptomforbindelser. Mønsterresultater er utforskende assosiasjoner, ikke bevis på matintoleranse eller allergi.
